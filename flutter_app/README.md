# FridgeChef — Flutter (Android)

Native Android frontend for FridgeChef. Mirrors the three-state flow from the web app: upload → ingredient chips → recipe cards.

## Prerequisites

- [Flutter SDK 3.22+](https://docs.flutter.dev/get-started/install) on your PATH.
- Android Studio (or just the Android command-line tools + SDK) for a device emulator.
- The FridgeChef backend running on your laptop at `http://localhost:8000`.

Verify Flutter:

```
flutter doctor
```

All "Flutter," "Android toolchain," and "Android Studio" rows should be green.

## First-time setup

This directory ships only the app source (`pubspec.yaml`, `lib/`). You need Flutter to generate the platform scaffolding (`android/`, `ios/`, `.metadata`, etc.) once.

From the repo root:

```
cd flutter_app
flutter create . --org com.fridgechef --project-name fridgechef --platforms=android
flutter pub get
```

That populates `android/` without touching the existing `pubspec.yaml` or `lib/`.

### Allow cleartext HTTP

The dev backend speaks plain HTTP. Android blocks that by default. Edit `flutter_app/android/app/src/main/AndroidManifest.xml` and add `android:usesCleartextTraffic="true"` to the `<application>` element:

```xml
<application
    android:label="fridgechef"
    android:icon="@mipmap/ic_launcher"
    android:usesCleartextTraffic="true">
```

### Camera + gallery permissions

`image_picker` reads them automatically on Android 13+. No manifest edits needed for typical use.

## Run

### Emulator

```
flutter run
```

The emulator reaches your host via `http://10.0.2.2:8000` — already wired as the default.

### Physical device on same Wi-Fi

Find your laptop's LAN IP (e.g. `192.168.1.42`), then:

```
flutter run --dart-define=FRIDGECHEF_BASE_URL=http://192.168.1.42:8000
```

Also make sure your backend listens on all interfaces, not just localhost:

```
uvicorn backend.main:app --host 0.0.0.0 --port 8000
```

…and your laptop firewall allows inbound TCP/8000 from the LAN.

## Layout

```
flutter_app/
├── pubspec.yaml       — dependencies (http, image_picker)
├── lib/
│   ├── api.dart       — Api client + Recipe / RecipeIngredient models
│   └── main.dart      — entry point + UploadScreen, IngredientsScreen, RecipesScreen
└── android/           — generated by `flutter create .` (not in repo)
```

## Build a release APK

```
flutter build apk --release
```

The APK lands in `flutter_app/build/app/outputs/flutter-apk/app-release.apk`.
